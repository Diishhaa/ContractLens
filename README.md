# ContractLens AI — Understand Before You Sign

**ContractLens AI** is a mobile-first web application developed for the **Hack-A-Agent Hackathon**. It helps everyday citizens (students, freelancers, job seekers, renters) parse and understand complex legal documents before signing them, converting legal language into clear, accessible English.

The app's primary intelligence engine is the OpenAI-compatible **ASI:ONE API**, using specialized reasoning models to audit clauses, highlight hidden liabilities, and answer follow-up questions contextually.

## Core Features
1. **Multi-Format Extraction**: Upload legal documents in PDF or Image format (PNG, JPG, JPEG) for automatic text extraction (via server-side parsing and OCR).
2. **ASI:ONE Contract Simplifier**: Translates dense legal terms into plain English.
3. **Four-Card Analysis Dashboard**:
   * **Simple Summary**: Explain the contract in clear 2-3 sentences.
   * **Key Points**: Bulleted breakdowns of obligations, payments, and notice periods.
   * **Important Warnings**: Color-coded badges for hidden fees, strict penalties, and auto-renewals.
   * **Questions to Ask**: Actionable questions to ask the counterparty before signing.
4. **Context-Aware Chat**: Follow-up chat interface powered by ASI:ONE context memory to ask specific questions like *"Can they terminate me without cause?"* or *"Am I liable for damages?"*.
5. **Interactive Question Chips**: Click any question in the warnings/questions cards to auto-send it to the AI for immediate feedback.
6. **Hackathon Demo Mode**: High-speed offline-ready demonstration mode containing a pre-loaded employment contract to show instant analysis.

---

## Tech Stack
* **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Lucide Icons.
* **Backend**: Next.js API Routes (Node.js runtime).
* **Document Processing**: `pdf-parse` (PDF selectable text extraction), `tesseract.js` (Image OCR).
* **AI Engine**: ASI:ONE API (`asi1-ultra` for deep reasoning, `asi1` for conversation).

## Quick Start Guide

### 1. Configure Environment
Copy the example environment variables file and fill in your API key:
```bash
cp .env.example .env.local
```
Inside `.env.local`:
```env
ASI_ONE_API_KEY=your_asi_one_api_key_here
```

### 2. Install Dependencies
Install packages:
```bash
npm install
```

### 3. Run Development Server
Start the local server:
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## Hackathon Demo Flow
To showcase ContractLens AI at the hackathon, follow these steps:
1. Open the homepage.
2. Click the **"Try Demo Contract"** button. This loads a predefined Employment Agreement with uneven termination notices, intellectual property assignments, and strict non-compete clauses.
3. Inspect the contract in the scrollable preview pane.
4. Click **"Analyze with ASI:ONE Engine"** to see the pulsing loader screens.
5. Review the generated summary dashboard cards (Simple Summary, Key Points, Important Warnings, Questions to Ask).
6. Click the quick prompt chip: **"What is the biggest risk in this contract?"** or type a custom question in the chat.
7. Witness the contextual, plain-English response generated by ASI:ONE.

## Vercel Deployment
To deploy this project to Vercel:
1. Push your repository to GitHub.
2. Connect your repository to **Vercel**.
3. Add the Environment Variable `ASI_ONE_API_KEY` in the Vercel dashboard.
4. Click **Deploy**. Next.js App Router configurations will compile and host serverless routes automatically.
